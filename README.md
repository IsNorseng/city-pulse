# Пульс города

[Открыть дашборд](https://isnorseng.github.io/city-pulse/)

Цены жилья в Санкт-Петербурге и Краснодаре и расчёт вашего личного бюджета. Это фиксированный проверенный срез: данные не обновляются автоматически.

## Какие данные есть

Восемь показателей жилья из трёх публикаций ЦИАН. Первичные страницы прочитаны напрямую 4 октября 2026 года. Все значения — средние, не медианы.

| Показатель | Санкт-Петербург | Краснодар | Период среза |
| --- | ---: | ---: | --- |
| Аренда однокомнатной, ₽/месяц | 45 600 | 26 300 | Сентябрь 2026 |
| Аренда двухкомнатной, ₽/месяц | 67 200 | 42 400 | Сентябрь 2026 |
| Цена м² вторичного жилья, ₽/м² | 290 800 | 144 700 | Сентябрь 2026 |
| Стоимость однокомнатной на вторичном рынке, ₽ | 10 500 000 | 5 500 000 | Январь 2026 |

Аренда — ставки в объявлениях о долгосрочной аренде без элитных квартир. Цена м² — цена предложения. Для стоимости однокомнатной источник не уточняет, использованы объявления или состоявшиеся продажи. Размер городских выборок не опубликован.

Месяц обозначает срез публикации, а не среднее за весь календарный месяц; точный день замера неизвестен. Январские и сентябрьские цены относятся к разным срезам.

## Ваш личный бюджет

Введите свой доход и расходы на ЖКХ, продукты, транспорт и связь. Аренда по умолчанию равна опубликованной средней ставке однокомнатной квартиры выбранного города; её можно заменить своей суммой. Пока обязательные поля не заполнены, остаток не рассчитывается. Нулевой расход нужно указать явно.

**Остаток = доход на руки − аренда − ЖКХ − продукты − транспорт − связь.** Отрицательный остаток показывает дефицит выбранного бюджета.

Для дохода «До налога» модель предполагает одинаковую зарплату каждый месяц, налоговое резидентство РФ, отсутствие вычетов и других доходов. Прогрессивный годовой НДФЛ усредняется по 12 месяцам. Для дохода «На руки» налог повторно не вычитается. Основание — [публикация ФНС](https://www.nalog.gov.ru/rn78/news/activities_fts/15766617/); параметры и допущения сохранены [отдельно](data/evidence/ndfl-rules.json).

Это ваш сценарий, а не статистика дохода типичного жителя. Введённые суммы остаются в памяти страницы, не отправляются на внешний сервер и сбрасываются при перезагрузке.

## Ограничения

Этот выпуск показывает жильё и личный бюджет. Полная экономика городов, официальные зарплаты, вакансии HH, инфляция, потребительские корзины, МСП, безработица, демография и образование в него не включены.

Официальные показатели из PDF Росстата исключены: документы не удалось прочитать напрямую при проверке. Поисковые фрагменты не считаются достаточным подтверждением. [Журнал исключённых источников](docs/excluded-sources.json) содержит ссылки и причины, без неподтверждённых чисел. Ошибка доступа не доказывает ошибку публикации.

Отсутствующие данные не заменяются нулями, оценками или данными региона. Временного ряда и прогноза нет. Соотношение цены квартиры и годового дохода не показывает срок накопления: расходы на жизнь, ипотека, расходы на покупку и изменение цен не учтены.

## Запуск из исходников

Проект использует React, TypeScript и Vite. Нужны Node.js 22.13+ и npm.

```sh
npm ci
npm run check
npm run dev
```

Откройте локальный адрес из вывода. Сервер разработки слушает `127.0.0.1`.

```sh
npm run build
npm run build:local
```

`dist/` содержит обычную сборку сайта. Вторая команда создаёт `local-output/Пульс города.html`: автономный файл с интерфейсом и данными, который можно открыть без сервера. Интернет нужен только для перехода к первоисточникам.

`npm run check` проверяет типы и согласованность рабочего набора с сохранёнными выписками: значения, единицы, город, период, тип цены и отсутствие выдуманного размера выборки. Команда не загружает свежие публикации и не подтверждает их актуальность.

Рабочий набор — [verified-observations.json](data/verified-observations.json). [Контрольные суммы](docs/snapshot-sha256.json) позволяют определить точный сохранённый набор файлов. Серверного импорта и автоматического обновления данных нет.
